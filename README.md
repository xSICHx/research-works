# Научно-исследовательские работы 

Репозиторий содержит проекты, выполненные в рамках учебной и исследовательской деятельности. Каждая работа демонстрирует применение теоретических знаний к практическим задачам в области ML, обработки данных и распределённых систем.

---

### 1 sem: Logistic Regression (Python)
**Бинарная классификация клиентов банка**  
- Данные: 20k клиентов Santander Totta (21 признак)  
- Методы: L1/L2/ElasticNet регуляризация, оптимизация (lbfgs/saga)  
- Инструменты: Scikit-Learn, Pandas

### 2 sem: Теория вероятностей  
**Решение 11 задач из учебника Н.Ш. Кремера**  
- Темы: формулы Байеса/Бернулли/Пуассона, интегральная теорема Муавра-Лапласа  
- Приложения: страховые выплаты, контроль качества, дни рождения  
- Результат: доказательство независимости вероятностей от порядка действий, расчёты для больших выборок

### 3 sem: Kafka Streams (С#, Java)  
**Анализ событий Telegram-бота в реальном времени**  
- Архитектура: бот (producer) → Kafka → Kafka Streams → consumer  
- Метрики: популярность команд, средние закупки, активности пользователей  
- Результат: рабочая система для мониторинга мероприятия ДВФУ, код [Telegram Bot](https://github.com/xSICHx/DVFUTelegramBotC-/tree/kafka/TelegramBotDVFU), код [Kafka Streams](https://github.com/xSICHx/KafkaStreams)

### 4 sem: Linear Regression (R)  
**Оптимизация для больших данных**  
- Методы: аналитическое решение vs градиентный спуск (распараллеливание через `parallel`)  
- Результаты:  [Исходный код](https://github.com/statmod-courseworks/lr-gd-r-npogrebnikov/)

---

🛠 **Технологии**: Python (Scikit-Learn, Pandas), R (parallel), Apache Kafka, теория вероятностей  
📊 **Ключевые навыки**: классификация, потоковая обработка, распределённые вычисления, статистическое моделирование
